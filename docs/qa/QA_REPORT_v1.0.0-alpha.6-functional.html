Defects and reproduction evidence

Critical

DEF-MDCR-001 — Pipeline composition crashes the renderer

Impact: adding a valid guided command to the pipeline raises an uncaught exception. Subsequent version, workspace, entry, and field interactions can repeat the failure until the app is reloaded or pipeline state is cleared.

Reproduction:

  1. Open Build and select the guided journalctl unit-log task.
  2. Set unit to sshd.service, priority to err, since to today, and current boot to yes.
  3. Choose Add to pipeline or press Ctrl+Shift+P.
  4. Observe the exception in renderInspector.

Expected: the pipeline renders Stage 1 and the rest of the interface remains usable. Actual: the renderer dereferences a null catalog entry.

Major

DEF-MDCR-002 — User-specific recipes have no editable parameters

Impact: the app presents fixed examples as “Copy command” output. A user trying to search for laundry receives grep -rn -i "pattern" /etc and cannot choose the search term, search location, or flags. Copy succeeds technically, but the copied command does not complete the stated task.

Expected for grep: controls for search text, path, case sensitivity, recursion, line numbers, and other supported flags, followed by a reviewed command such as grep -rn -i "laundry" /target/path. Actual: zero editable fields and zero flag controls.
