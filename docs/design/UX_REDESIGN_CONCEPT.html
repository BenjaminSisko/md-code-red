MD CODE RED / UX REVAMP
Design concept · 30 September 2026 · not production code
Concept direction · Operational field manual

Make the command the hero. Reveal the evidence when it earns attention.

MD CODE RED already has more authority, safety, and RHEL-specific context than lightweight command generators. The redesign turns that depth into a staged workflow: find the task in plain language, configure only what matters, review the exact command and risk, then open verification and compliance details on demand.

Task first

Search by goal or browse Diagnose, Change, Automate, Comply, and Learn. Tool names remain a secondary path.

One decision at a time

Use Build → Review → Verify. Hide advanced fields and long teaching text until requested.

Command always visible

Keep a sticky, readable preview beside the form on desktop and above the form on mobile.

Trust stays explicit

RHEL version, blast level, verification state, source, and recovery remain visible without flooding the main task.

Observed product patterns

Competitive benchmark

The goal is selective adaptation. Fast generators win on focus and first-use clarity; MD CODE RED wins on deterministic output, release awareness, evidence, and operational recovery.
