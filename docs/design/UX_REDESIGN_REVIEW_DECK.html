SALM user-research lens

Busy operators skip different things

Administrator

Skips long explanations. Needs exact prerequisites, an honest consequence, and recovery when the change fails.

Instructor

Needs progressive reveal, expected output, release comparison, and a distraction-free teaching surface.

Automation engineer

Needs stable fields, predictable quoting, stage composition, output-path risk, and exact copy behavior.

Compliance staff

Needs a visible chain from requirement to command to capture to verified execution.

The design must let experts move quickly while keeping verification and recovery within one action.

Accessibility and interaction review

Fix these before calling the new shell complete

Evidence dialog needs focus entry, containment, background isolation, Escape, and focus return.
Search needs a complete accessible combobox/listbox contract.
Rerenders currently destroy focus after several state changes.
Command lines expose “Line N” instead of the command text to assistive technology.
The entire editor is a live region and can announce a large page on every keystroke.
Copy, validation, and refusal messages need a small stable status region.
Hints and errors need programmatic association with fields.
Muted text, success text, focus rings, and form boundaries include measured contrast failures.
The 1025-pixel state can leave roughly 305 pixels for the editor.
Mobile primary navigation and nested scrolling create reflow and focus risks.
